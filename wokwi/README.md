# Wokwi Simulation

The Wokwi simulation provides an interactive representation of the
Automated Commercial Micro-Climate Nursery. As Wokwi does not provide a separate
capacitive soil moisture sensor and pump, potentiometers have been used in place

## Simulation

https://wokwi.com/projects/475381934405977089

## Simulated Features

- DHT22 temperature and humidity monitoring
- LDR-based light monitoring
- Automated grow-light control
- Servo-controlled ventilation
- Soil-moisture simulation
- OLED system display
- Manual override
